# Telechat downloads

Installers for the Telechat desktop app. Pick the latest release on the right.

- Mac (Apple Silicon): Telechat-<version>-mac-arm64.dmg
- Mac (Intel): Telechat-<version>-mac-x64.dmg
- Windows: Telechat-<version>-win-x64.exe

First launch on Mac: right-click the app and choose Open. On Windows: More info, then Run anyway.
